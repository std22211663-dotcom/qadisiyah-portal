بوابة تربية القادسية الإلكترونية

1. شغّل QadisiyahPortal.exe (لا يحتاج تثبيت Node أو أي برنامج آخر).
2. يفتح المتصفح تلقائياً. الدخول الأول: admin / Admin@123 (غيّر كلمة المرور فوراً).
3. يمكن للأجهزة على الشبكة نفسها الدخول بالعناوين الظاهرة في نافذة البرنامج.
4. البيانات والمرفقات في المجلد data بجانب البرنامج: انسخه للنسخ الاحتياطي.
5. لتغيير المنفذ (الافتراضي 3001) أنشئ ملف port.txt فيه الرقم فقط.
6. للإيقاف اضغط «إيقاف وإغلاق».
